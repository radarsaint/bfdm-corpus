Column guide:
*	marked with * if it's something i think i'd be able to make, either on commission or just sell like a normal shop (or different for different things). if we have an explosives expert then explosives should go there instead, just a lot of these items are cool and not seen often so
Animal	If it can be made solely with animal products.
ARn'T	If it can be made solely with animaln't products.
Mixed	If it can be made with a mixture of material types. If both the previous columns are ticked, this in most cases will be too. If neither of the previous columns are ticked but this is, it requires a mixture.
Reasoning	If none of the previous columns are ticked, this is my reasoning for rejecting crafting; otherwise, it's my reasoning for what boxes I ticked.
Extra	Just extra notes, not necessarily important. if i drop the brain tangents here they're easier to ignore 
the following categories i am not adding:
any firearms - we're using the homebrew ones, and even those fall under the artificer clause* to me
equipment pack - you can just make the stuff in it
mount - artificer clause (necromancy)
space vehicles, for obvious reasons; all water vehicles except the rowboat
artisan's tools / x's tools - these are more specialised and would be hard to make on the fly imo - even artificers need an hour and magic to do it - i could sell them though
artificer clause: there's some things that i think would need an expert to make (artificer clause because most of the ones i found would logically be made by artificers), such as alchemist's fire, explosives, guns, poison etc; those i'm not listing materials for as a result
potions/poisons likely will depend on if they say what they're made of in the description or not
if you want me to go through and mark things as 'you need to use x artisan's tool with proficiency to try and make this' i can do that
some poisons would probably be too expensive/complicated even then, but it'd give a use to tool kits in general
some items (mostly gems, at least one seed), i think could still work here except instead of /making/ them you're searching through in hope of finding it
I am using vanilla minecraft logic for some stuff, as well as crossreferencing wikipedia and encyclopedia britannica (where i can. hecker is locking me out sometimes)
vanilla because if we go modded we have. tinker's construct basically letting you make any weapon out of any material. i don't think bone tool rods would work here
some items don't have a price listed, I'm not going to try and work out a good price; these could all be changed anyway if needed
all firearms are excluded by default, other stuff i think excluding will be noted in reasoning
I say ticked but it's a y for yes, but details
i'm being more strict with martial weapons than simple ones, which i think is fair
